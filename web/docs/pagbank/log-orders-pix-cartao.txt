================================================================================
Majesté Fitness — Integração PagBank
API: Pedidos e Pagamentos (Orders)
Meios de pagamento a validar: PIX (qr_codes) + Cartão de crédito (CREDIT_CARD)
Ambiente: Sandbox — https://sandbox.api.pagseguro.com
Loja: https://amajeste.com.br
Notification URL: https://amajeste.com.br/api/webhooks/pagseguro
Observação: checkout transparente no próprio domínio. NÃO utilizamos
Divisão de Pagamentos / split.
================================================================================

================================================================================
RESUMO
================================================================================
- API de Pedidos e Pagamentos (Orders): POST /orders
- Cartão de crédito: payment_method.type = CREDIT_CARD, card.encrypted (encryptCard)
- PIX: qr_codes (QR Code exibido no checkout do site)
- Notificação de pagamento via notification_urls (webhook)
- Sem Divisão de Pagamentos / split
================================================================================
